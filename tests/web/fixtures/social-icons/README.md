# Test-Icons

Nur für die Browser-Tests (`test_layouts.py`). Es sind einfache geometrische Formen (Kreis,
Quadrat), **keine** Logos. Die Tests leiten Anfragen an `assets/social-icons/` hierher um.
Für `instagram`, `tiktok` und `x` liegt absichtlich keine Datei hier. Damit wird der
Rückfall auf Text geprüft.
